Project overview

Config-Driven Native HTML5 <datalist> Autocomplete

json-to-dom-datalist compiles tabular data into native browser <datalist> autocomplete dropdowns. It extracts distinct values, calculates frequency counts, and builds declarative specs for json-to-dom with zero external dependencies.

What it does

  • Computes distinct values and frequency counts from column datasets.
  • Generates W3C-valid <datalist> and <option> JSON specifications.
  • Renders directly into live DOM elements mounted inside a container.
  • Binds to native browser <input list="..."> with zero JavaScript overhead on the input.
  • Dynamically refreshes options via .update({ inData }) without full page reloads.
  • Ships with zero external dependencies and instant npx json-to-dom-datalist scaffolding.

Why developers choose it

  • Zero styling conflicts — renders with native browser OS autocomplete UI.
  • Complete mobile device keyboard integration (iOS & Android).
  • Accessible by default without custom ARIA role workarounds.
  • High-speed grouping and frequency calculation via groupBy.js.
  • Integrates natively with json-to-dom-form and json-to-dom.
