Tasks & Roadmap

Current features, verified capabilities, and upcoming milestones for json-to-dom-datalist.

Completed Milestones

  • Config-driven HTML5 <datalist> options generator.
  • Distinct value aggregation with occurrence counts (groupBy.js).
  • Decoupled modular architecture (DataListStore, actions, methods).
  • Universal compatibility in Node.js (SSR / test runner) and browsers via globalThis.
  • Dynamic real-time updates via .update({ inData }).
  • Zero-dependency npx json-to-dom-datalist CLI.
  • Automated node --test unit test suite with 100% pass rate.

Upcoming Roadmap

  • Remote asynchronous data provider resolution (dataProvider).
  • Custom label template formatting functions.
  • Debounced search filtering hook for massive datasets (>50,000 items).
  • Integration recipes with json-to-dom-form and json-to-dom-table.
