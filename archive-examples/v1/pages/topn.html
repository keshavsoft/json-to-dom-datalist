Top-N filtering

For large datasets, showing every unique value in a datalist creates noise. Pass topN in your config (or column definition) to surface only the most frequently occurring values — keeping autocomplete lean and useful.

⚠️ Use the slider to change topN live. The side-by-side panels show how the same data looks with and without the limit. Drag it to 0 for unlimited.

Code

Pass topN via config or inline on the column.

// Via config (applies to all columns)
const dl = new DataList({
  inData: data,
  inColumns: columns,
  inConfig: {
    datalist: { topN: 3 },   // show only top 3 per column
  },
});

// Or per-column override
const columns = [
  { key: "stockitemname", datalistId: "stock-dl", topN: 5 },
  { key: "batchname",     datalistId: "batch-dl"  },   // inherits global topN
];
