Dynamic load & update

Real apps don't have static data. Use a dataProvider function to lazily fetch rows on demand, or push data directly with update(). Both methods automatically re-render all <datalist> elements.

Simulated async fetch with dataProvider async · load()

A dataProvider function receives the query object from load({ inQuery }). The DataList calls it, awaits the result, updates its store, and re-renders all datalists.

When you already have the data in memory, skip the provider and call dl.update({ inData: newRows }). The store is replaced and all datalists re-render instantly.

Code patterns

Copy-paste ready.

// ── Pattern 1: dataProvider + load() ──────────────────────────────
const dl = new DataList({
  inColumns: columns,
  inDataProvider: async ({ vchtype } = {}) => {
    const res = await fetch(`/api/vouchers?type=${vchtype ?? ""}`);
    return res.json();
  },
});
dl.renderStructure({ inContainerId: "mount" });

// Fetch sales vouchers — datalists rebuild automatically
await dl.load({ inQuery: { vchtype: "Sales/CA" } });
// ── Pattern 2: update() with in-memory data ───────────────────────
const dl = new DataList({ inData: [], inColumns: columns });
dl.renderStructure({ inContainerId: "mount" });

// Later — push data directly, datalists re-render instantly
dl.update({ inData: newRows });
