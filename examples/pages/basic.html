Basic usage

Create a DataList with static data, define which columns to index, call renderStructure(), and wire the generated <datalist> IDs to your inputs. That's it.

Code walkthrough

The full pattern in under 20 lines.

import & setup
import { DataList } from "json-to-dom-datalist";

// Your flat JSON rows
const data = [
  { "stockitemname": "ROPE",    "batchname": "Tuf-Rs.170" },
  { "stockitemname": "ROPE",    "batchname": "Tuf-Rs.170" },
  { "stockitemname": "Plastic Tray", "batchname": "PT-Batch-A" },
];

// Column definitions: key = dot-path in your rows, datalistId = <input list="">
const columns = [
  { key: "stockitemname", datalistId: "stock-dl" },
  { key: "batchname",     datalistId: "batch-dl" },
];

// Create and render
const dl = new DataList({ inData: data, inColumns: columns });
dl.renderStructure({ inContainerId: "my-mount-div" });
wire your inputs
<!-- Just set list="" to the datalistId you defined -->
<input list="stock-dl" placeholder="Stock item…" />
<input list="batch-dl"  placeholder="Batch name…" />

<!-- Mount target (the datalist wrapper will be injected here) -->
<div id="my-mount-div"></div>
