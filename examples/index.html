How it works

Four concepts, zero dependencies.

Step 01

Define columns

Each column maps a key (dot-path) from your data rows to a datalistId used on your <input list="">.

Step 02

Create DataList

Instantiate new DataList({ inData, inColumns, inConfig }). The store indexes values immediately.

Step 03

Render to DOM

Call renderStructure(). A hidden #ks-datalists-wrapper div with all <datalist> elements is injected.

Step 04

Wire your inputs

Set list="your-datalist-id" on any input. The browser autocomplete works natively — no JS event handlers needed.
