Engine Architecture

Modular Internal Structure & Clean Separation

Aligned with KeshavSoft standards, json-to-dom-datalist decouples state management, spec builders, lifecycle methods, and actions into isolated units.

Folder Hierarchy (src's Highest Version)

src/v2/
├── common/
│   ├── SourceStore.js      // Base catalog resolver
│   ├── cloneData.js        // Deep immutability
│   ├── groupBy.js          // Distinct counts
│   └── pruneTreeWithIds.js // Control tree extraction
├── datalist/
│   ├── DataList.js         // Orchestration class
│   ├── actions/            // load, update actions
│   ├── methods/            // buildSpec, renderStructure
│   ├── datalistStore/      // DataListStore.js
│   ├── datalistBuilder/    // buildDataList, buildOptions
│   └── render/             // DOM attachment
└── index.js                // Universal globalThis export
